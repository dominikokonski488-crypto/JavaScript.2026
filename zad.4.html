1)kiedy powstał JavaScript (podaj datę).


JavaScript powstał oficjalnie 4 grudnia 1995 roku.


2)dlaczego jest to język skryptowy


JavaScript jest nazywany językiem skryptowym, ponieważ jego kod nie wymaga wcześniejszej kompilacji (tłumaczenia całego pliku na język maszynowy przed uruchomieniem), lecz jest interpretowany i wykonywany na bieżąco przez specjalny silnik w przeglądarce internetowej lub innym środowisku.


3)gdzie jest wykonywany JS (klient lub serwer)


JavaScript jest wykonywany po stronie klienta (w przeglądarce), ale z użyciem Node.js może być również wykonywany po stronie serwera.


4)dlaczego jest JS to bezpieczne narzędzie


JavaScript jest uważany za bezpieczny język skryptowy, ponieważ działa w kontekście przeglądarki i nie ma dostępu do zasobów systemowych, co ogranicza potencjalne zagrożenia dla bezpieczeństwa.


5)czy jest to język obiektowy , jeśli tak to dlaczego.


Tak, JavaScript jest językiem obiektowym, ponieważ umożliwia tworzenie obiektów i manipulowanie nimi za pomocą metod i właściwości.


6)wymień zalety JS:


Umożliwia pisanie kodu w stylu obiektowym, funkcyjnym oraz proceduralnym.


Kod po stronie klienta (w przeglądarce) wykonuje się natychmiastowo, co odciąża serwer i przyspiesza reakcję aplikacji.


Dzięki mechanizmom takim jak Promises i async/awit, JS doskonale radzi sobie z obsługą wielu zadań jednocześnie (np. pobieraniem danych w tle) bez zawieszania interfejsu.


7)Framework to:


Framework to zestaw narzędzi i bibliotek, które ułatwiają rozwój oprogramowania, dostarczając gotowe rozwiązania do typowych zadań programistycznych.


8)Do aplikacji mobilnych można użyć Framework


Do aplikacji mobilnych można użyć Framework, np. React Native, Flutter czy Ionic.


9)Aplikacje responsywne to:


Aplikacje responsywne to aplikacje, które automatycznie dostosowują się do rozmiaru i orientacji ekranu urządzenia, na którym są uruchamiane.
