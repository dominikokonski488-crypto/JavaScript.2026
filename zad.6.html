Rodzaje okienek:

  • Okienko alert – wyświetlają okienko dialogowe z informacją i przyciskiem OK.
  • Okienko prompt – generują okno, w którym użytkownik może wpisać wartość, zwracana następnie do programu.
  • Okienko confirm służy do tego, aby użytkownik coś potwierdził (stąd nazwa confirm).

Przy nadawaniu nazw zmiennym należy przestrzegać pewnych zasad:

  1. Nazwa zmiennej musi się zaczynać od litery, znaku "_" lub "$" , może zawierać tylko litery (bez polskich znaków), cyfry oraz znak "_" i "$".
  2. Wielkość liter ma znaczenie.
  3. Należy nie używać słów kluczowych JavaScript jako nazw zmiennych.

Typy zmiennych w JavaScript

W JavaScript nie ma możliwości definiowania różnych typów zmiennych jak w C++, typy zmiennych są definiowane w trakcie ich przypisywania.

Podstawowe zmienne liczbowe w JavaScript to:

  • Number → Typ liczbowy
  • zmienna całkowite
  • zmiennoprzecinkowe

String → Typ tekstowy
Boolean → Typ logiczny
Null → Pusta wartość
Undefined → Typ niezidentyfikowany
